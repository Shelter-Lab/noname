# 牌堆构成与「牌堆补充」机制

> 每次靠对话临时算一遍太慢，故把机制和结论固化在这里。
> 数字全部由 `node scripts/pile-ratio.mjs` 从源码算出，改了卡牌包重跑即可。

## 一、机制：牌堆怎么装配的

### 1. 包 → 牌堆（`apps/core/noname/init/loading.ts` `loadCard`）

```
lib.config.cards 里勾选的每个包 → 取它的 list
  → 按 lib.config.bannedpile[包名]（**index 数组**）过滤掉禁用的那几张
  → 再拼上 lib.config.addedpile[包名]
  → addArray 进 lib.card.list
```

要点：

- **`bannedpile` 存的是 index，不是牌名。** 上游若调整了某个包 `list` 的顺序，旧存档里的禁用勾选就会**错位到别的牌上**。
- 单机模式下**不做 `mode` 过滤**。带 `mode: ["guozhan"]` 的卡（敕令 / 挟天子以令诸侯 / 勠力同心 / 玉玺 / 诏书 …，国战包里共 15 张）在身份局开了国战牌堆后会**真的进牌堆**。`mode` 过滤只在联机分支（`apps/core/noname/game/index.js:8023`）和 `game.findCards` 里有。
- 默认只开两个包：`"cards": ["standard", "extra"]`（`dist/game/config.json:164`）。

### 2. 牌堆补充（`apps/core/extension/cardpile/extension.js`）

这是个 `play` 扩展，在 `arenaReady`（游戏界面创建后、开局前）往 `lib.card.list` 里追加牌：

```js
num = Σ round(参照表张数 × 该类倍率)          // 倍率：补充全部 1 / 补充一半 0.5 / 不补充 0
dn  = num × (lib.card.list.length − 160) / (160 − num)   // 上限 1000
各类追加 = round(dn × 该类 getn / num)        // 花色照参照表，点数随机 1~13
```

**参照表是「军争 160 张」的固定字面量**（`extension.js:8-62`），和你实际开了哪些包毫无关系：

| 项 | 张数 | 默认倍率 |
|---|---|---|
| 杀 | 30 | 1 |
| 火杀 | 5 | 1 |
| 雷杀 | 9 | 1 |
| 闪 | 24 | 1 |
| 桃 | 12 | 0 |
| 酒 | 5 | 0 |
| 无懈可击 | 7 | 0.5 |
| 南蛮入侵 | 3 | 0 |
| 万箭齐发 | 1 | 0 |
| 过河拆桥 | 6 | 0 |
| 顺手牵羊 | 5 | 0 |
| 铁索连环 | 6 | 0 |
| **合计** | **113** | |

（表里写的 total 是 160，而 `standard + extra` 实际 161 张 —— 差 1 张，量级上无影响。）

### 3. 由公式推出的关键结论

倍率全开时 `num = 113`，于是每往牌堆里加 **1 张牌**，会连带补充 `113/47 ≈ 2.404` 张，合计 `+3.404` 张；其中杀 = `该包自身杀密度 + 44/47(≈0.936)`。

> **边际杀密度 = (包杀密度 + 0.936) / 3.404**

- 一个 **0 杀**的包 → `0.936/3.404 = 27.5%`，**正好等于当前杀比例，完全不稀释杀**
- 一个 **27% 杀**的包（军争水平）→ `35.4%`，**反而把杀比例拉高**

所以「开扩展包会把杀稀释掉」这个直觉，在**开了牌堆补充之后是错的**。被稀释的是**装备和锦囊**，杀只会持平或变多。

反过来，**关掉补充**才是真正的稀释：见下表场景④，杀从 27.3% 掉到 24.3%、装备飙到 25.4%。

## 二、数字：各场景实测

`node scripts/pile-ratio.mjs`（2026-08-13，禁用的 5 张 = 寒冰剑 / 方天画戟 / 八卦阵×1 / 诸葛连弩×1 / 藤甲×1）

| 场景 | 总张数 | 基本 | 装备 | 锦囊 | 延时 | 杀 | 闪 | 桃 | 杀:闪 |
|---|---|---|---|---|---|---|---|---|---|
| ① 军争基准（standard+extra，不补充） | 161 | 52.8% | **16.1%** | **26.7%** | 4.3% | 44 (27.3%) | 24 (14.9%) | 12 | 1.83 |
| ② +曹操传，禁 5 张，全部补充 | 229 | 53.3% | **20.1%** | **23.6%** | 3.1% | 63 (27.5%) | 35 (15.3%) | 17 | 1.80 |
| ③ 同②但用默认补充档 | 196 | 51.0% | 23.5% | 21.9% | 3.6% | 54 (27.6%) | 29 (14.8%) | 12 | 1.86 |
| ④ 同②但关掉补充 | 181 | 47.0% | 25.4% | 23.8% | 3.9% | 44 (24.3%) | 24 (13.3%) | 12 | 1.83 |

**②对比①的真实变化**：杀的比例**基本没动**（27.5% vs 27.3%），动的是
**装备 16.1% → 20.1%（+4pp）、锦囊 26.7% → 23.6%（−3pp）**。

「感觉杀少了」的来源不是杀变少，而是装备变多：每摸 5 张牌多 0.2 张装备，
而装备既不能当杀用，装上以后还**永久离开循环**（杀/锦囊打完会回弃牌堆重洗）。

  --packs standard,extra,caocaozhuan,zhulu,sp \

## 六、游戏里在哪调

- **开关某个卡牌包**：选项 → 卡牌 → 左侧包名下方的开关（只有开/关，不能改数量）
- **禁用单张牌**：选项 → 卡牌 → 左侧选「编辑牌堆」→ 展开某个包 → 逐张勾选（写进 `bannedpile`）
- **加牌（可指定张数）**：同上「编辑牌堆」里的三个下拉（花色/点数/牌名），初始 `hidden`，
  展开后才出现（`apps/core/noname/ui/create/menu/pages/cardPackMenu.js:371-430`，写进 `addedpile`）
- **牌堆补充**：选项 → 扩展 → 牌堆补充（`cardpile`），逐项设 补充全部/一半/不补充
